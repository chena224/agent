# 知识库概况报告技能

把知识库平台的实时统计变成一份可存档的概况报告。

## 执行步骤

1. 调用 `kb_stats` 获取当前用户可见的知识库列表与各自文档/索引规模(该工具已按调用者权限过滤,数据可直接引用)。
2. 调用 `current_time` 获取报告生成时间。
3. 按以下结构输出报告:

## 输出格式

### 知识库概况报告

- **报告时间**:(取自 current_time)
- **总体规模**:可见知识库 N 个,已建索引 M 个
- **分库明细**:Markdown 表格,列为 `知识库 | 文档 | 索引块数 | 状态`
- **概况小结**:2~3 句话,指出规模最大/最小的库、是否存在未建索引的库

## 要求

- 所有数字以工具返回为准,不得估算或虚构;
- 用户可见列表为空时,直接说明"当前没有可访问的知识库",不要编造示例数据;
- 需要更细粒度(如某库文档清单)时,提示用户到「知识库」页面查看。
