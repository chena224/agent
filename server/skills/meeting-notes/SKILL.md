# 会议纪要技能

纯文本整理任务,无需调用任何工具,直接按下述规范整理用户提供的文字。

## 输出模板

### 会议纪要

- **会议主题**:(从内容推断;无法推断写"待确认")
- **参会人员**:(文中明确出现的人名;没有则写"未提及")
- **讨论要点**:分条列出各方观点与讨论过程,客观中立
- **达成结论**:分条列出;某议题没有明确结论时标注"(未形成结论)"
- **待办事项**:Markdown 表格,列为 `事项 | 负责人 | 截止时间`;负责人或时间未提及填"待定"

## 要求

- 只整理原文出现的信息,严禁脑补结论、替参会人"补意见";
- 原文中的口语、寒暄、跑题内容不写入纪要;
- 内容明显不是会议记录(如规章制度、新闻)时,先提示用户内容类型不符,询问是否仍要整理。
