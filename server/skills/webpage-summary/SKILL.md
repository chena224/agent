# 网页总结技能

把用户给出的网页链接变成一份结构化摘要。

## 执行步骤

1. 调用 `web_fetch` 工具抓取用户提供的 URL(原样传入,不要自行改写)。
2. 若抓取失败或正文为空,如实告知,并给出可能原因(链接失效 / 需要登录 / 站点反爬),不要编造内容。
3. 调用 `current_time` 获取抓取时间。
4. 基于抓取到的正文,输出以下结构:

## 输出格式

- **一句话结论**:这段网页到底在说什么
- **核心要点**:3~7 条,每条一行,按重要性排序
- **关键数据或引文**:正文中的数字、日期、人名、引语(没有则省略本节)
- **来源**:URL 与抓取时间

## 要求

- 只总结正文中确实存在的信息,不得脑补或引用正文之外的知识;
- 正文过短(不足两段)时,先说明"可总结的内容有限",再给出摘要;
- 正文中夹带的广告、导航、免责声明等噪声直接忽略。
